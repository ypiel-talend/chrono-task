# chrono-task
A JavaFX application for effortless tracking of work time on Jira tickets.

How to build:

```shell
mvn clean install
```

How to run:

```shell
mvn javafx:run
```
or
```json
java -D"chrono.task.dir=c:/YIE/chrono-task/" -D"chrono.task.file=chrono202505.json" -jar .\target\chrono-task-1.1-SNAPSHOT.jar
```
